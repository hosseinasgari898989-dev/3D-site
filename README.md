# 3D-site — Shareable Formula

این repository مرجع قابل اشتراک برای ساخت سایت‌های سینمایی و 3D-style است.

## Included
- Scroll storytelling + sticky scenes
- SVG trail / path drawing / nodes
- Layered backgrounds
- Glow + glass + gradient depth
- 3D hover tilt
- Reveal animations
- Search / toast / theme / performance controls
- Reduced-motion support
- Responsive / mobile-first behavior
- Local fonts: IBM Plex Sans Arabic + Geist Mono
- Zero framework dependency
